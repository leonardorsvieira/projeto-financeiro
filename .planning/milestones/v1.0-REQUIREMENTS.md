# Requirements: Meu Bolso (v1.0)

**Defined:** 2026-09-05 | **Shipped:** 2026-09-06
**Core Value:** O usuário dita um gasto, recebimento ou investimento pela voz e ele é registrado corretamente, no lugar certo, pronto para acompanhar — sem digitação manual.

## v1 Requirements — shipped neste milestone

### Plataforma e Acesso (PLAT)

- [x] **PLAT-01**: Usuário único faz login com e-mail e senha e permanece logado entre sessões no celular e na web — *Validated v1.0 (Fase 1)*
- [x] **PLAT-02**: App roda no Android e no iPhone a partir do mesmo código — *Validated v1.0 (Fase 1): código Flutter multi-plataforma; build web deployado; validação em dispositivo Android/iOS pendente de toolchain*
- [x] **PLAT-03**: Usuário acessa os mesmos dados pelo navegador no PC — *Validated v1.0 (Fase 1): GH Pages público + realtime*
- [x] **PLAT-04**: Lançamentos feitos em qualquer dispositivo ficam sincronizados (dados na nuvem) — *Validated v1.0 (Fase 2): Supabase realtime*
- [x] **PLAT-05**: Dados financeiros trafegam por HTTPS e são armazenados com segurança (auth), sem vazar para o repositório público — *Validated v1.0 (Fases 1-2): RLS por usuário, chaves fora do git*

### Captura por voz (VOZ)

- [x] **VOZ-01**: Usuário dita um gasto e a IA transcreve, extrai valor, categoria e forma de pagamento, e o lançamento só é salvo após confirmação com um toque — *Validated v1.0 (Fase 3): UAT real aprovado; modelo final `gemini-3.5-flash-lite` (free tier)*
- [ ] **VOZ-02**: Usuário dita recebimentos (ex.: "recebi 3000 de salário") e a IA registra como receita — *Fase 7 (futuro)*
- [ ] **VOZ-03**: Usuário dita lançamentos de investimento (ex.: aporte/compra) pela voz — *Fase 8 (futuro)*
- [ ] **VOZ-04**: Usuário dita o vencimento/agendamento do dia de pagamento de uma despesa — *Fase 4 (futuro)*
- [ ] **VOZ-05**: Usuário dita os itens/produtos detalhados de uma compra — *Fase 4 (futuro)*
- [x] **VOZ-06**: Em caso de dúvida na captura, o app pede confirmação das informações extras (vencimento, itens) em vez de gravar errado — *Validated v1.0 (Fase 3): confirmação pré-preenchida editável antes de salvar*

### Despesas (DSP)

- [x] **DSP-01**: Usuário lança despesa manualmente com valor, categoria, forma de pagamento, data e notas — *Validated v1.0 (Fase 2)*
- [x] **DSP-02**: Usuário edita e exclui lançamentos existentes — *Validated v1.0 (Fase 2)*
- [x] **DSP-03**: Formas de pagamento disponíveis: cartão de crédito, débito, Pix, dinheiro e outros — *Validated v1.0 (Fase 2)*
- [ ] **DSP-04**: Usuário adiciona itens/produtos detalhados a uma despesa — *Fase 4 (futuro)*
- [ ] **DSP-05**: Usuário agenda o dia do pagamento/vencimento de uma despesa — *Fase 4 (futuro)*

### Recorrências e lembretes (RECT)

- [ ] **RECT-01**: Usuário pode lançar uma despesa manualmente OU marcá-la como fixa mensal (valor recorrente todo mês) — *Fase 4 (futuro)*
- [ ] **RECT-02**: Sistema envia lembrete push "X dias antes" do vencimento, com X configurável — *Fase 5 (futuro)*
- [ ] **RECT-03**: Sistema reapresenta o lembrete no dia do vencimento no horário escolhido pelo usuário — *Fase 5 (futuro)*
- [ ] **RECT-04**: Usuário visualiza a lista de próximos vencimentos de faturas e contas — *Fase 5 (futuro)*

### Dashboard (DASH)

- [ ] **DASH-01**: Usuário vê o saldo do mês (entradas − saídas, considerando previstos) na primeira tela — *Fase 6 (futuro)*
- [ ] **DASH-02**: Usuário vê gráfico de gastos por categoria — *Fase 6 (futuro)*
- [ ] **DASH-03**: Usuário vê a lista de próximos vencimentos na primeira tela — *Fase 6 (futuro)*
- [ ] **DASH-04**: Usuário define meta/limite de gasto por categoria e vê o progresso — *Fase 6 (futuro)*

### Investimentos (INV)

- [ ] **INV-01**: Usuário registra e acompanha ações e FIIs — *Fase 8 (futuro)*
- [ ] **INV-02**: Usuário registra e acompanha cripto — *Fase 8 (futuro)*
- [ ] **INV-03**: Usuário registra e acompanha renda fixa — *Fase 8 (futuro)*
- [ ] **INV-04**: Usuário registra e acompanha investimentos de banco digital (carteiras automáticas) — *Fase 8 (futuro)*
- [ ] **INV-05**: Usuário vê patrimônio total e rendimento acumulado — *Fase 8 (futuro)*
- [ ] **INV-06**: Usuário vê dividendos/rendimentos recebidos por mês — *Fase 8 (futuro)*
- [ ] **INV-07**: Usuário registra compras e vendas de cada ativo — *Fase 8 (futuro)*

## v2 Requirements

### Integrações

- **INTG-01**: Importação automática de extratos/transações de bancos
- **INTG-02**: Open Finance para leitura de faturas de cartão
- **INTG-03**: Assistente conversacional por voz (IA que responde e pergunta)

### Compartilhamento

- **COMP-01**: Múltiplos usuários/família com contas em comum

## Out of Scope (mantido)

| Feature | Reason |
|---------|--------|
| Integração Open Finance / importação de extratos no v1 | Sem dados bancários automáticos; registro é por voz/manual. Adiado para v2 |
| IA assistente conversacional | Restrição "IA gratuita" — v1 é ditado inteligente (transcrever + extrair), não conversa |
| Multiusuário/família | Uso individual escolhido na definição |
| IA paga | Restrição de custo: STT e LLM gratuitos (Gemini free tier) |
