# Plan 06-02: Gráfico de gastos por categoria (DASH-02)

## Goal
Mostrar no dashboard (aba Resumo) um **donut chart** dos gastos do mês por categoria, com legenda e valores. Decisão: usar `fl_chart`.

## Context
- 06-01 entregará `HomeScreen` (tabs) e `dashboard_providers.dart`.
- `Lancamento.categoria` (string PT-BR, lista fixa em `lancamento_converter.dart`).
- Fase 6 sem receitas — "gastos por categoria do mês" = soma `valorCents` agrupada por `categoria` dos lançamentos com `data` no mês vigente.

## Scope
**Inclui:**
- Dependência `fl_chart` no `pubspec.yaml`.
- Provider `gastosPorCategoriaMesProvider` (agrupado, ordenado desc, com cores).
- Widget `DonutGastosCategoria` no `DashboardScreen`: donut + legenda (categoria, % e R$).
- Empty state quando não houver gastos no mês.
- Testes: agregação correta; legenda/valores renderizados.

**Exclui:**
- Metas (06-03).
- Comparação com meses anteriores / linha do tempo.

## Technical Design
- `fl_chart: ^1.1.0` (última; Dart >=3.6 OK — Flutter 3.47).
- `GastoCategoria` record: `(categoria, valorCents)`.
- Provider: `ref.watch(lancamentosStreamProvider).valueOrNull` → filtrar `data` no mês → agrupar → sort desc.
- Paleta: mapa categoria→cor (reutilizar lista fixa) com fallback.
- Widget: `PieChart` com `PieChartSectionData` (sectionRadius, color, value via `showTitle: false`; % central opcional) + coluna de legenda.
- Donut em `SizedBox` ~200x200; legenda abaixo com `Row` de chip (cor, categoria, valor, %).

## Acceptance Criteria
1. Donut mostra categorias do mês com proporção correta (soma = gasto real do mês).
2. Legenda lista cada categoria com R$ e %.
3. Sem gastos → empty state ("Sem gastos neste mês").
4. `flutter analyze` limpo; testes passam.
5. Build web e APK OK (fl_chart compatível com web).
