# Plan 05-01: Tela "Próximos Vencimentos"

## Goal
Criar uma tela (S7) acessível da lista principal (S5) que mostra os lançamentos com vencimento futuro, ordenados por data (mais próximos primeiro).

## Context
- Fase 4 já implementou: `Lancamento.vencimento`, `fixoMensal`, `serieId`, itens.
- `lancamentosStreamProvider` emite a lista completa de lançamentos do usuário.
- Notificações locais (04-04) já agendam T-3 e T-0.

## Scope
**Inclui:**
- Nova rota `/proximos-vencimentos` (S7) no `AppRoutes`.
- Entry point na S5 (AppBar ou FAB secundário).
- Lista filtrada: só lançamentos com `vencimento != null` E `vencimento >= hoje`.
- Ordenação: `vencimento` ascendente.
- Item da lista: descrição, valor, categoria, data vencimento (badge), indicador fixa mensal.
- Pull-to-refresh (revalida cópias vigentes via `ensureVigenteCopies`).
- Empty state amigável.

**Exclui:**
- Edição/criação na tela (já existe fluxo S6/S8).
- Push FCM/APNs (05-02, opcional futuro).
- Configuração X dias (05-03, plano separado).

## Technical Design
- `ProximosVencimentosScreen` (ConsumerWidget) em `presentation/`.
- Reutiliza `Lancamento` domain e `formatoData`/`formatoBRL`.
- Filtro no provider: novo `proximosVencimentosProvider = Provider<List<Lancamento>>((ref) { final all = ref.watch(lancamentosStreamProvider).valueOrNull ?? []; return all.where((l) => l.vencimento != null && !l.vencimento!.isBefore(DateTime.now())).toList()..sort((a,b) => a.vencimento!.compareTo(b.vencimento!)); })`.
- Rota: `GoRoute(path: AppRoutes.proximosVencimentos, builder: ...)`.
- Botão na S5: `IconButton(Icons.event_outlined, tooltip: 'Próximos vencimentos')` → `context.push(AppRoutes.proximosVencimentos)`.

## Acceptance Criteria
1. Ao abrir S7, vê lista ordenada dos vencimentos futuros.
2. Vencimentos passados não aparecem.
3. Lançamento fixo mensal aparece apenas a cópia do mês corrente (já garantido por `ensureVigenteCopies`).
4. Pull-to-refresh atualiza a lista.
5. Navegação S5 → S7 → back funciona.
6. `flutter analyze` limpo; testes passam.
