# Plan 05-03: Configuração de Dias Antes (X) e Horário

## Goal
Permitir que o usuário configure quantos dias antes do vencimento quer ser avisado (X), além do horário (já feito no 04-04). Padrão: 3 dias.

## Context
- 04-04 implementou `PreferenciasLembretes` (hora/minuto) + `NotificacoesService.datasDeAgendamento` fixo em T-3/T-0.
- `LembretesController` sincroniza com `lancamentosStreamProvider`.
- UI S5 já tem IconButton para editar horário.

## Scope
**Inclui:**
- Estender `PreferenciasLembretes` com `diasAntes: int` (padrão 3, mínimo 0, máximo 30).
- Persistir em `SharedPreferences` (`lembretes_dias_antes`).
- Atualizar `NotificacoesService.datasDeAgendamento` para usar `diasAntes` (T-X e T-0).
- UI S5: diálogo unificado (horário + dias antes) — `showDialog` com `TimePicker` + `NumberPicker` (ou slider/stepper).
- `LembretesController.alterarPreferencias` recebe objeto completo e reagenda.
- SnackBar confirma "Lembretes: X dias antes às HH:mm".

**Exclui:**
- Múltiplos lembretes (ex: T-7, T-3, T-1) — só X e T-0.
- Push FCM/APNs (05-02).

## Technical Design
- `PreferenciasLembretes` → adiciona `diasAntes` (default 3). `toMap`/`fromMap` atualizados.
- `PreferenciasService` → carrega/salva `diasAntes`.
- `NotificacoesService.datasDeAgendamento(venc, hora, minuto, diasAntes)` — calcula `venc.subtract(Duration(days: diasAntes))` para T-X.
- `LembretesController.alterarPreferencias(prefs)` — salva + invalida provider + reagenda.
- UI: `_abrirPreferenciasLembretes` abre `AlertDialog` com `TimePicker` + `TextField` numérico (ou `NumberPicker` custom) para dias.

## Acceptance Criteria
1. Usuário abre config na S5, define dias antes = 5 e horário = 18:30 → SnackBar confirma.
2. Lançamento com vencimento daqui 10 dias: agenda notificação T-5 (5 dias antes) e T-0 (dia).
3. Lançamento com vencimento em 2 dias (diasAntes=5): só agenda T-0 (T-X já passou).
4. `diasAntes = 0` → só notifica no dia (T-0).
5. Mudança de preferências reagenda todos os vencimentos futuros.
6. `flutter analyze` limpo; testes passam.
