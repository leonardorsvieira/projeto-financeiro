# Plan 08-05: Captura de aporte/investimento por voz (VOZ-03)

## Goal
Usuário dita investimentos ("comprei 10 PETR4 a 38,50", "aportei 500 no CDB", "recebi 120 de dividendos da BBSE3") e a IA cria ativo + movimento (+ rendimento) após confirmação.

## Context
- Fase 3/7: ditado → `RascunhoLancamento` → `ConfirmacaoDitadoScreen`. Prompt schema hoje: `"tipo": "despesa"|"receita"`.
- Decisão D-06: estender a classificação para `"tipo": "investimento"` com campos de investimento; fluxo de confirmação próprio.

## Scope
**Inclui:**
- `GeminiPrompt` (payload de reconhecer): schema ganha `"tipo": "despesa"|"receita"|"investimento"`; quando investimento, campos `investimento_classe` (`acao`/`fii`/`cripto`/`renda_fixa`/`banco_digital`), `investimento_nome`, `operacao` (`compra`/`venda`/`aportar`/`dividendo`), `quantidade`, `preco_unitario` (R$), `valor` (aporte/RF/bco ou dividendo), `data`. Regras: sinais "comprei", "compre", "comprei X de", "aportei", "investi", "vendi", "resgatei", "recebi dividendos", "rendimento de". Fallback `despesa`.
- `RascunhoInvestimento` (domain: classe, nome, operacao, quantidade, precoUnitCents, valorCents, data) + `parseRascunho` extrai ambos (rascunho lançamento x investimento).
- `DitadoController`/repositório: `reconhecer` devolve `RascunhoDitado` unificado (lançamento OU investimento) → rota decide `ConfirmacaoDitadoScreen` vs `ConfirmacaoInvestimentoScreen`.
- `ConfirmacaoInvestimentoScreen`: pré-preenche ativo (busca/classe/nome/quantidade/preço, operacao, data); salvar cria/atualiza ativo + movimento (+ rendimento se operacao=dividendo) via repositories de 08-01/02/04.
- Testes: prompt (schema investimento + parse), controller (rota confirmação investimento), tela de confirmação (salvar cria ativo+movimento), flow completo.

**Exclui:** editar preço atual por voz, múltiplos ativos numa frase (1 por ditado), correção por voz campo-a-campo de investimento (MVP: re-ditar).

## Acceptance
1. "comprei 10 PETR4 a 38,50" → confirmação investimento → ativo PETR4 (ação) criado + compra, quantidade 10, preço R$ 38,50.
2. "aportei 500 no CDB" → renda_fixa CDB com movimento aporte (valor 500).
3. "recebi 120 de dividendos da BBSE3" → ativo BBSE3 criado + rendimento dividendo 120.
4. Palavras não relacionadas continuam despesa/receita sem quebrar fluxo existente.
5. `flutter analyze` limpo; todos os testes verdes.
