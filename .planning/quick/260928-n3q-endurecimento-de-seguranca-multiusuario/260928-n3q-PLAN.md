# Endurecimento de segurança multiusuário

Auditoria de 2026-09-28 (repo GitHub **público**, app usado pelo dono + convidados):

- `client_secret` da Pluggy hardcoded em `open_finance_repository.dart` → commitado (dcbc988) e embutido no `main.dart.js` do GitHub Pages.
- Conta Pluggy compartilhada: `buscarItensConectados` lista `/items` de **todos** os usuários → vazamento de bancos/transações entre clientes (RLS não cobre, dados vêm da Pluggy).
- `GEMINI_API_KEY` via `--dart-define` → vai para o bundle web público.
- Cadastro aberto com autoconfirm; leaked-password protection desligada.
- Logout não limpa `SharedPreferences` (credenciais/contas Open Finance, cartões), notificações agendadas nem widget.
- Android sem `allowBackup=false`; web sem CSP; sem varredura de segredos no CI.

## Tarefas

1. **Migration** `pluggy_items` (dono de cada item Pluggy, RLS select-own, sem escrita pelo cliente), `uso_diario` + `consumir_cota()` (security definer, só service_role), revogar tudo de `anon` no schema public.
2. **Edge Functions** (`supabase/functions/`):
   - `_shared/seguranca.ts`: usuário autenticado + e-mail confirmado, cota diária, CORS com allowlist.
   - `pluggy`: proxy com allowlist de rotas; injeta `clientUserId`; só devolve items/contas/transações de items do próprio usuário.
   - `ditado`: proxy do `generateContent` do Gemini com allowlist de modelos, limite de tamanho e cota diária.
3. **App**: `EdgeFunctionEndpoint` em `core/`; `PluggyOpenFinanceService` e `GeminiDitadoRepository` passam a chamar as funções; remover `PluggyCredentials`/`defaultCreds`/diálogo de credenciais; logout limpa dados locais, notificações e widget.
4. **Build/CI**: remover `GEMINI_API_KEY` de `deploy.yml`, `build_apk.ps1`, `.env.example`, `env.dart`, README; workflow gitleaks.
5. **Plataforma**: `allowBackup=false` (Android), CSP no `web/index.html`.
6. **Docs**: CLAUDE.md/PROJECT.md multiusuário.
