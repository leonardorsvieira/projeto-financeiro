# Plan 08-01: Modelo e tela de investimentos/ativos (4 classes)

## Goal
Registrar ativos nas 4 classes (ação/FII, cripto, renda fixa, banco digital) com tabelas no Supabase, domínio, repositórios e tela dedicada `/investimentos` com CRUD simples.

## Context
- Não há nenhum conceito de investimento no código (mapeado: zero ocorrências de ativo/cotação/portfolio).
- Padrão de feature estabelecido (Metas): domain → repository (interface + supabase) → providers → tela sem Scaffold próprio via rota dedicada.
- Decisões D-01..D-05, D-08.

## Scope
**Inclui:**
- Migration `20260907170000_create_investimentos.sql` com as 3 tabelas (padrão `metas`: RLS por `user_id`, realtime, uuid) — ver D-02 para schema.
- Domínio: `TipoClasseInvestimento` (`acao`, `fii`, `cripto`, `renda_fixa`, `banco_digital` com `dbValue`/`rotulo`/`ePrecificaoPorQuantidade`), `Investimento` (id, classe, nome, quantidade double, precoAtualCents, saldoCents) com `toMap`/`fromMap` e getter `patrimonioCents`/`ePorQuantidade`.
- `InvestimentosRepository` (interface): `watch()`, `create`, `update`, `delete`; `SupabaseInvestimentosRepository` (stream `.order('nome')`, quase nenhuma join).
- `investimentosRepositoryProvider` + `investimentosStreamProvider`.
- Tela `InvestimentosScreen` (`/investimentos`): `ProviderScope` ConsumerWidget; se tiver Scaffold próprio? → **sem Scaffold próprio não**; Padrão: com Scaffold próprio (Metas tem). Lista por grupo de classe (ordem fixa: Renda Fixa, Banco Digital, Ações, FIIs, Cripto) com card por ativo (nome, classe, patrimônio, variação vs custo não nesta fase); FAB "+" novo ativo; menu editar/excluir por ativo.
- `InvestimentoFormScreen` (novo/edição) como dialog ou rota: campos Nome, Classe (Dropdown), Quantidade (double, somente se classe por quantidade), Preço atual (R$) ou Saldo (somente RF/bco), salvar.
- Rota `/investimentos` + `investimentoNovo` + `investimentoEditar(id)`; ação no AppBar da Home (ícone `pie_chart_outline`) como Metas.

**Exclui:** movimentos (08-02), patrimônio agregado/ganho (08-03), rendimentos (08-04), voz (08-05).
