# Plan 03-01 — Captura de voz + cliente Gemini (dados)

**Phase:** 3 | **Plan:** 1 of 3 | **Status:** Ready | **Date:** 2026-09-06
**Wave:** 1

## Objetivo
Infraestrutura de dados do ditado: gravação push-to-talk e cliente Gemini REST que transcreve áudio → rascunho de lançamento (JSON), mais a correção campo-a-campo.

## Tasks

### 1. Dependência `record` (web)
- `flutter pub add record` (suporta web/MediaRecorder). Confirmar no pubspec `record: ^5.x`.
- Verificação: `flutter pub get` ok.

### 2. Domínio — `RascunhoLancamento`
- `app/lib/features/ditado/domain/rascunho_lancamento.dart`: campos nullable (descricao, valorTexto, categoria, formaPagamento, dataIso, vencimentoIso). `copy`-like para merge de correção.
- `app/lib/features/ditado/domain/ditado_repository.dart`: `Future<RascunhoLancamento> reconhecer(LancamentoAudio audio)` e `Future<String?> corrigirCampo(CampoCampo campo, {Uint8List? audio, String? texto})` (enum campo: descricao/valor/categoria/forma/data/vencimento).
- `rascunho_lancamento_test.dart`: construtor/merge.

### 3. Dados — `GeminiDitadoRepository`
- `Prompt` fixo em pt-BR: papel (contador financeiro), regras (valor em texto BRL, escolher categoria/forma **das listas fixas da Fase 2**, null quando não citado, data hoje se ausente, apenas campos citados), pedido de JSON.
- HTTP: `POST .../models/gemini-2.5-flash:generateContent` header `x-goog-api-key` (dart-define `GEMINI_API_KEY`), body `contents[{parts:[{text},{inline_data audio/webm}]}]`, `generationConfig{responseMimeType: application/json}`.
- Parse: extrair JSON do `candidates[0].content.parts[0].text` → `RascunhoLancamento.converterFromJson`.
- `corrigirCampo`: mesmo endpoint, prompt menor: "extraia apenas {campo} do áudio/texto; retorne só o valor do campo (ou null)".
- Config: usar `package:http` direto (evitar dep nova de cliente Gemini); key via `String.fromEnvironment`.
- `gemini_prompt.dart` separado p/ testar prompt+parse sem rede.
- `gemini_ditado_repository_test.dart`: HTTP mock (package:http/testing MockClient) — sucesso JSON, campo nulo, erro → exception tipada (`DitadoException` com mensagem amigável).

### 4. Gravação — `AudioRecorderService` (abstração sobre `record`)
- `app/lib/features/ditado/data/audio_recorder_service.dart`: `start()/stop()` → `({Uint8List bytes, String mime})`; `hasPermission()`; estado via `ValueNotifier<RecState> (idle/gravando/processando)`.
- `record` web: `AudioRecorder.start(RecordConfig(encoder: AudioEncoder.webmOpus, numChannels: 1))`, `.stop()` → bytes.
- Teste com fake (não rodar mic em CI).

### 5. Providers
- `ditadoRepositoryProvider`, `audioRecorderServiceProvider` (ref.autoDispose), `ditadoControllerProvider` (StateNotifier: `gravar()`, `parar()` → chamar IA → `cancelar()`).
- Teste unitário do controller com fakes.
