### 4. S8 — `confirmacao_ditado_screen.dart`
- Extratores: extrair campos comuns do form Fase 2 (builder `_CampoLancamento` com trailing opcional "🎤 Corrigir") para reuso.
- Recebe `RascunhoLancamento`; pré-preenche campos (descrição, valor via parser, dropdowns, data/vencimento).
- Cada campo com ação voz: grava 1 frase → `corrigirCampo` → merge no form (resto preservado).
- Valor ausente → foco no campo Valor (D-36).
- Salvar: cria `Lancamento` e chama `lancamentosRepositoryProvider.create` (reuso) → pop até lista. Botão Salvar com `_isSaving` (anti duplicação).
- Cancelar → pop.
