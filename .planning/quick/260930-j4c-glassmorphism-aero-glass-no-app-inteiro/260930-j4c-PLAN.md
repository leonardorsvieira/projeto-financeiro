  <action>
    Write tests first in app/test/theme/glass_test.dart (plain MaterialApp with ThemeData light/dark; no Supabase needed), watch them fail, then implement app/lib/theme/glass.dart (per D-01, D-02, D-04):

    1) `GlassTokens` (immutable class, static `of(BuildContext)` derived from `Theme.of(context).brightness`): `fill` (light: Colors.white alpha ~0.55; dark: Color(0xFF0C1A16) alpha ~0.45), `fillForte` for dialogs/sheets/inputs where legibility matters (light: white ~0.78; dark: Color(0xFF0C1A16) ~0.72), `borda` (light: white ~0.30-0.45 so it is visible on the pale background; dark: white ~0.14-0.18), `sombra` (black alpha ~0.06 light / ~0.20 dark, blurRadius ~24, offset (0,8)), `sigma` = 20, `raio` = 20 (cards) and `raioGrande` = 28 (dialogs/sheets). Expose also a `static BorderSide bordaDe(Brightness)` / `static Color fillDe(Brightness, {bool forte})` helper so app_theme.dart (which has no BuildContext) can reuse the SAME values.

    2) `GlassBackground({required Widget child})`: Stack(fit: StackFit.expand) with a RepaintBoundary + IgnorePointer static background layer, then the child. Background = DecoratedBox LinearGradient (topLeft -> bottomRight). Light: pale mint ~#DDF3E8 -> pale teal ~#CFEDEB -> pale petrol ~#CBDFEA. Dark: ~#06140F -> ~#072020 -> ~#0A1B26. Plus 3-4 soft "blobs" positioned with Positioned/Align using fractions of size (LayoutBuilder), each a Container with a RadialGradient from a color to transparent (NO ImageFilter — radial falloff looks blurred and is cheap on web/CanvasKit and low-end Android): brand green AppTheme.seed-ish #0B7A4B, teal #14B8A6, petrol #0E5E7A, a lighter green #34D399; alpha ~0.35-0.45 in light, ~0.25-0.35 in dark. Background is static (not animated). Make it fully opaque (the base gradient colors are opaque) so it can hide whatever is below.

    3) `GlassSurface({required Widget child, BorderRadius? borderRadius, EdgeInsetsGeometry? padding, bool blur = false, bool forte = false})`: Container decoration with tokens fill, 1px Border.all(tokens.borda), borderRadius (default raio), boxShadow [tokens.sombra]. When `blur` is true wrap it in ClipRRect(borderRadius) + BackdropFilter(ImageFilter.blur(sigmaX: sigma, sigmaY: sigma)). Doc comment in Portuguese: use blur only on a few big surfaces (app bar/tab bar, hero cards); never in repeated list items (performance on web/low-end Android).

    4) `GlassCard({required Widget child, EdgeInsetsGeometry? margin, bool blur = true})`: renders `Card(margin: margin, color: Colors.transparent, elevation: 0, shadowColor: Colors.transparent, surfaceTintColor: Colors.transparent, clipBehavior: Clip.antiAlias, shape: RoundedRectangleBorder(radius raio), child: GlassSurface(blur: blur, borderRadius: same, child: child))` — keeps the Card type in the tree for existing tests.

    5) `GlassPageTransitionsBuilder extends PageTransitionsBuilder` with a `final PageTransitionsBuilder base` (const constructor): `buildTransitions` returns `base.buildTransitions(route, context, animation, secondaryAnimation, GlassBackground(child: child))`. Purpose: every pushed page carries its own opaque background (scaffold is transparent), so the page below never shows through during/after transitions. Keeps iOS swipe-back when base is CupertinoPageTransitionsBuilder.

    No glossy highlights, no sheen gradients on surfaces (D-01). Imports: dart:ui (ImageFilter), package:flutter/material.dart, ./app_theme.dart only if needed for seed (avoid circular import problems — putting the seed color literal in glass.dart is fine).
  </action>
